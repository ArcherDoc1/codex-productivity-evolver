# 使用示例

## 1. 检查本地项目状态

```text
用 codex-productivity-evolver 的方式检查这个项目能不能正常启动。
```

期望行为：

- 先读取项目结构和启动脚本。
- 检查依赖、端口、环境变量和日志。
- 给出最小可行修复，不扩大改动范围。
- 完成后说明验证方式。

## 2. 修改配置

```text
帮我把服务端口改成 8080，按自我进化 skill 的流程做。
```

期望行为：

- 找到配置来源。
- 说明影响范围。
- 必要时备份。
- 修改后运行可用的测试或启动检查。
- 给出回滚方式。

## 3. 排查启动失败

```text
项目启动失败，帮我看日志并修复。
```

期望行为：

- 不先猜测原因，先查看真实错误。
- 区分依赖缺失、端口占用、环境变量错误、代码异常。
- 每次只改一个明确问题。
- 最后给出根因和验证结果。

## 4. 处理高风险操作

```text
帮我清理磁盘空间。
```

期望行为：

- 先列出大文件和候选目录。
- 区分可再生成缓存、项目依赖、用户资料、备份文件。
- 删除前明确询问或使用可回滚移动方案。
- 不自动清空用户目录、OneDrive、数据库或未知目录。

## 5. 沉淀经验

```text
把这次修复流程总结成以后可复用的 skill 规则。
```

期望行为：

- 提炼触发条件。
- 补充检查命令。
- 写清楚不能直接做什么。
- 加入验证和回滚步骤。
